## Tech Stack
- **Framework:** Next.js 14 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS (System-aware Dark/Light mode with Linear-inspired design aesthetics)
- **Motion:** Framer Motion
- **Icons:** Lucide React

## Local Development
```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production Build
